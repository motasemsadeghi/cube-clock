# مکعب ساعت، تقویم و هوا

یک مکعب سه‌بعدی که روی وجه‌هایش ساعت، تقویم و هواشناسی زنده نمایش داده می‌شود. به‌صورت وب‌اپ (PWA) روی گیت‌هاب پیج‌ز اجرا می‌شود و مثل یک نرم‌افزار نصب می‌شود.

## وجه‌ها

| وجه | نمایش |
|---|---|
| ساعت عقربه‌ای | ثانیه، دقیقه و ساعت روی کمان‌های چهارتکه؛ هر ۶ ساعت صفحه یک‌چهارم می‌چرخد |
| تقویم | روز هفته، روز و ماه شمسی و میلادی روی کمان‌ها |
| هواشناسی | دما، دمای احساسی، نقطه شبنم، رطوبت، UV و کیفیت هوا برای موقعیت فعلی |
| ساعت دیجیتال | ساعت، دقیقه و ثانیه (روبه‌روی ساعت عقربه‌ای) |
| تاریخ دیجیتال | تاریخ شمسی، میلادی و ترکی همراه با شماره ماه (روبه‌روی تقویم) |
| هوا دیجیتال | مقادیر عددی هواشناسی (روبه‌روی هواشناسی) |

## استفاده

- **چرخاندن:** با انگشت یا ماوس روی مکعب بکشید.
- **آوردن یک وجه جلو:** روی همان وجه کلیک یا تپ کنید.

## موقعیت مکان

به ترتیب زیر انتخاب می‌شود:

1. پارامتر آدرس: `?lat=41.03&lon=28.67&name=استانبول`
2. GPS دستگاه (مرورگر اجازه می‌پرسد؛ برای کار کردن باید HTTPS باشد)
3. موقعیت تقریبی از روی IP
4. آخرین موقعیت ذخیره‌شده
5. پیش‌فرض: اسنیورت، استانبول

داده‌ها از [Open-Meteo](https://open-meteo.com) و نام شهر از BigDataCloud گرفته می‌شود و هر ۱۵ دقیقه به‌روز می‌شود. کلید API لازم نیست.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | خود برنامه (همه‌چیز در یک فایل) |
| `manifest.webmanifest` | نام، آیکون و حالت نصب |
| `sw.js` | اجرای آفلاین (سرویس‌ورکر) |
| `icon-192.png`، `icon-512.png` | آیکون برنامه |

## انتشار روی گیت‌هاب پیج‌ز

1. همه فایل‌ها را در ریشه مخزن آپلود کنید.
2. در **Settings ← Pages** شاخه `main` را انتخاب کنید و ذخیره کنید.
3. بعد از چند دقیقه برنامه در `https://USERNAME.github.io/REPO/` در دسترس است.

## نصب مثل نرم‌افزار

- **Edge / Chrome (ویندوز و اندروید):** روی آیکون نصب در نوار آدرس کلیک کنید، یا از منو گزینه *Install this site as an app* را بزنید.
- **iPhone (Safari):** دکمه اشتراک‌گذاری ← *Add to Home Screen*

## به‌روزرسانی

بعد از تغییر فایل‌ها، عدد نسخه کش را در `sw.js` بالا ببرید (`cube-v1` ← `cube-v2`) تا نسخه جدید روی دستگاه‌های نصب‌شده جایگزین شود.

## اندازه مکعب

در `index.html` متغیر `--s` اندازه مکعب را تعیین می‌کند (پیش‌فرض: `min(48vmin,460px)`). اگر در پنجره‌ای کوچک جا نشد، عدد `48vmin` را کمتر کنید.
